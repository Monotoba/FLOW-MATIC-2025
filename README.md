# FLOW-MATIC 2025 

## Revisitation of Grace Hopper's Flow-Matic Programming System

---

If you love retro programming, it doesn't get much more retro than FLOW-MATIC!  
Flow-Matic was a popular programming system developed by Grace Hopper in 1955.  
It was designed for business data processing and was used in the US Department of Defense.  
The system was later used in the US Air Force and NASA.  

Flow-Matic was a very simple programming system that used a stack-based architecture.  
It was designed to be easy to learn and use, and it was also very efficient.  
The system was also very flexible, allowing users to create their own subroutines.  

In this repository, I've revisited the Flow-Matic programming system and create a modern interpreter for it.  
I'm also adding some extensions to the interpreter, such as a console I/O extension and a currency conversion extension.
You can see a full list of extensions in the `docs` folder, refer to the (index.md)[docs/index.md or (manual.md)[docs/manual.md files.

FLOW-MATIC 2025 also includes a simple extension mechanism to allow users to create their own extensions.  
This mechanism allows users to create their own extensions and integrate them into the interpreter.

I hope you enjoy using the interpreter and find it useful as a teaching tool or for reliving the early days with nostalgia!
